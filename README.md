# Projeto Node.js com TypeScript

Este repositório contém a estrutura inicial de um projeto Node.js configurado com TypeScript, atendendo aos requisitos do exercício de variáveis e funções.

## 📋 O que foi feito

- **Ambiente e Configuração:** Inicialização do Node.js (`package.json`) e configuração do compilador TypeScript (`tsconfig.json`).
- **Variáveis Tipadas (`src/nivel1.ts`):** Exemplos práticos declarando tipos como `string`, `number` e `boolean`.
- **Funções Tipadas:**
  - Funções com tipagem explicita em parâmetros e retornos.
  - Arrow Functions assíncronas utilizando `Promise`.
